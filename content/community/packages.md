# Community Packages

> <div class="warning">
> <b>Caution:</b> These packages are neither maintained nor vetted by the NoAiDarling core team.
> 
> Use them at your own risk.
> </div>

The NoAiDarling project has a growing ecosystem of community-maintained packages to extend NoAiDarling's capabilities on Linux systems.

## Overview

Community packages allow you to easily install pre-configured software, porting scripts, or third-party CLI utilities tailored for the NoAiDarling runtime.

Because these packages are maintained independently by community members:
* They may not follow the main project's release schedule.
* Compatibility with the latest NoAiDarling builds might vary.
* Security audits are the responsibility of individual package maintainers.

## Listing a Package

If you have created a package or wrapper for NoAiDarling and would like to share it with the community, feel free to submit a Pull Request to the [`NoAiDarling-docs`](https://github.com/NoAiDarling/NoAiDarling-docs) repository to add your project to this page.

### Submission Guidelines

When submitting a new community package, please include:
1. **Name and Link**: Direct URL to the repository or project page.
2. **Description**: A brief summary of what the package does or installs.
3. **Maintainer**: Your GitHub username or organization name.
4. **Status**: Indicate whether it's actively maintained, experimental, or deprecated.
